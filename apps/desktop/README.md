# 🖥️ Desktop Container (Tauri)

This folder contains desktop wrapper configuration for compiling the Next.js UI (`apps/web`) into a standalone native application using Tauri.

## 🚀 Native Features
* Native file pickers for `.rssh` subject package import and export.
* System tray and offline background daemon orchestration.
* Embedded webview pointing to local Next.js client (`http://localhost:3000`).
